# jolp.ai (formerly jolpai.tech)

Company site for JOLPAI - a single self-contained static page (`index.html` + `assets/`),
no build step. Deploy by uploading the repo contents to Hostinger (hPanel → File Manager).

Old template pages are kept as redirect stubs so indexed URLs still resolve.

Primary domain: **jolp.ai** (point DNS at Hostinger; keep jolpai.tech as a 301 redirect).
